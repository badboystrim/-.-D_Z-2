# Интернет-магазин "SkyShop"

Привет! Это мой учебный проект на Java. Я сделал мини-версию интернет-магазина, в котором есть корзина для покупок и поиск по сайту.

## Что я тут сделал:

1. **Создал разные товары:**
    * Обычные товары с простой ценой.
    * Товары со скидкой в процентах.
    * Товары, у которых цена всегда одинаковая (фикс-прайс).

2. **Сделал корзину:**
    * В неё можно добавлять товары.
    * Она умеет сама считать общую сумму всех покупок.
    * Из неё можно удалять товары по названию. Если удаляем "Хлеб", то он полностью убирается из корзины.

3. **Настроил умный поиск:**
    * Ищет и товары, и статьи на сайте по ключевым словам.
    * **Убрал дубликаты:** теперь нельзя добавить два одинаковых товара или две одинаковые статьи. Система их просто не пропустит.
    * **Сделал хитрую сортировку:** результаты поиска выводятся «лесенкой» — сначала самое длинное название, а в самом конце самое короткое. Если длина одинаковая, то они встают по алфавиту.
    * Добавил поиск лучшего совпадения: код ищет, где чаще всего встречается нужное слово. Если ничего не нашлось, программа не падает, а вежливо пишет ошибку в консоль.

4. **Защитил от дурака (валидация):**
    * Если попытаться создать товар без имени, с ценой 0 или с отрицательной ценой, программа сразу ругнется. Скидка больше 100% тоже не пройдёт.

## Как это запустить: ;)

1. Открываешь проект в IntelliJ IDEA.
2. Заходишь в файл `App.java`.
3. Жмёшь на зелёный треугольник (Run) вверху экрана.
4. Внизу в консоли побегут строчки — это тесты проверяют, как работает корзина, удаление и поиск.
