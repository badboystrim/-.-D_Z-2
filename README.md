# ДЗ по коллекциям (перевод на Мапы)

Переделал старое дз SkyShop, убрал линкедлисты и перевел все на Map, чтобы работало быстрее.

### Что изменил:
1. В ProductBasket заменил обычный список на HashMap. Теперь товары ищутся и удаляются по имени сразу через методы мапы, без тупых переборов и итераторов.
2. Для добавления заюзал computeIfAbsent, чтобы товары с одинаковыми именами нормально складывались в списки.
3. В SearchEngine переделал метод поиска, теперь он возвращает TreeMap. За счет этого все результаты сразу автоматом сортируются по алфавиту.
4. В классе App поправил только метод печати результатов, чтобы он принимал мапу и выводил значения через values().

Все тесты запускаются, выводится все четко и по алфавиту, как в критериях.
